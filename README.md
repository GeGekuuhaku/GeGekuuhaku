## Projetos

### [FlowTask](https://github.com/gabrielogutierrez/FlowTask) — gestão de tarefas full stack

Aplicação de produtividade com **Flutter, Dart, ASP.NET Core 8 e MySQL**.

- Autenticação JWT e senhas protegidas com PBKDF2
- CRUD de tarefas, categorias, prioridades, prazos, busca e filtros
- API REST documentada com Swagger
- Testes automatizados, Docker Compose e CI com GitHub Actions

### [FiscalFlow](https://github.com/gabrielogutierrez/FiscalFlow) — automação fiscal 🚧

Projeto em desenvolvimento para leitura de documentos fiscais, classificação de operações e geração de registros auditáveis com validação humana. Estruturado com **C#, .NET 10, ABP Framework, Entity Framework Core, Vue 3, TypeScript, PostgreSQL e Docker**.
